# System-Lab

系統軟體的自習實驗室。每個子專案都是「從零開始把一層基礎設施親手做出來」的完整紀錄。

重點不是做出能用的東西，而是**弄懂每一行為什麼要這樣寫**。因此每個子專案除了程式碼之外，
還會留下兩樣東西：

- **圖解教材**（`docs/guide/`）—— 原理。當下量到的數據、踩過的坑、被推翻的直覺
- **可執行實驗場**（`lab/`）—— 一個 `make` 指令跑一階，從最小可執行版本疊到完成品
